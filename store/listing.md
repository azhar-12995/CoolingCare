## Play Console — Data safety answers

- Does the app collect or share user data? **Collects, does not share.** Data is processed by Google Firebase as a service provider.
- Data types collected (all *required for app functionality*, not used for ads or analytics):
  - Personal info: **Name**, **Phone number**, **Address** (house / street, area)
  - Photos: **Photos** the user attaches to an order (optional)
  - App activity: **Other user-generated content** — orders, issue description, ratings
  - Device or other IDs: **Firebase Cloud Messaging token** (push notifications)
- Is data encrypted in transit? **Yes** (HTTPS / TLS to Firebase).
- Can users request deletion? **Yes** — Settings › Delete account (profile + login); order records on request via WhatsApp / phone.
- Account creation: phone-number log-in (Play policy: the in-app Delete account option satisfies the account-deletion requirement;
  also add a web deletion link or contact on the listing).
